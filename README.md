# Carbon-footprint-wheat
تطبيق بحثي لحساب وتحليل البصمة الكربونية لإنتاج القمح في مصر، من خلال بيانات المزرعة ومدخلات الإنتاج والطاقة والأسمدة والمبيدات والري والنقل والمخلفات، مع تصنيف الانبعاثات Scope 1, 2, 3 وحساب kg CO₂e/طن قمح، وتحليل مصادر الانبعاثات والسيناريوهات الاقتصادية والفنية لخفضها وتحسين كفاءة واستدامة الإنتاج.
